# Python, SQL and Machine Learning Practice

My practice work from HackerRank and Kaggle, covering Python programming, SQL, pandas, data visualisation and machine-learning workflows.

This repository is a learning collection alongside my Data Science master's studies. It brings together small coding challenges and guided notebooks, with the original exercise context retained.

## Viewing and using the files

Open the notebooks on GitHub to read their code and saved outputs.

HackerRank scripts generally follow the input format specified by the corresponding challenge. To run an individual script locally, use Python 3 and supply the expected input. NumPy exercises also require NumPy.

Kaggle notebooks may depend on Kaggle datasets, course helper packages, platform-specific paths or BigQuery access. Their original Kaggle environments provide the intended exercise context. Downloading a notebook alone does not necessarily include its data or supporting services.

There is no single entry point or shared installation command for the entire collection.
